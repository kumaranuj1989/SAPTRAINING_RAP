# S4D437 Transactional Apps with the ABAP RESTful Application Programming Model (RAP)

1.
Which of the following are included in the definition of Business Objects in RAP?
Choose the correct answers.
XACDS data modeling views
XBCDS behavior definitions
XCService bindings
XDBehavior implementations in ABAP classes
Correct! Business Objects in RAP consist of CDS data modeling views, CDS behavior definitions, and behavior implementations in ABAP classes.
2.

X
True
X

That is correct. A Business Object in RAP can either be a simple BO with a single node or a composite BO with a hierarchy of nodes.

Choose the correct answer.
XAtransactional_interface
XBanalytical_interface

What is the primary role of a Service Definition in the ABAP RESTful Application Programming Model?
Choose the correct answer.
XATo define the communication protocol for the service
XBTo define the scope of a business service, particularly the business object projection to be exposed
XCTo provide stable access to the functionality of a business object
